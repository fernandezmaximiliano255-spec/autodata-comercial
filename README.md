# AutoData Comercial

Proyecto de análisis comercial para una agencia ficticia de vehículos en Argentina.

## Tecnologías

- PostgreSQL
- SQL
- Power BI

No se utiliza Python para limpiar los datos: la información se carga limpia desde SQL, con tipos de datos, restricciones y relaciones definidas en la base.

## Tablas

- `sucursales`
- `vendedores`
- `clientes`
- `vehiculos`
- `ventas`
